# ZyXVirtual 0.3.7-alpha

Baseada diretamente na `v0.3.2-alpha` e assinada com a mesma keystore das releases anteriores.

Corrige o falso negativo do Binder no engine Native arm64: sockets Unix não são arquivos regulares, portanto a checagem usa `exists()` e valida o processo e o log do `binderd` sem bloquear quando ele já está escutando.

Também trata a ausência dos símbolos JNI opcionais do `aemugl` como fallback de software, sem abortar o boot com `UnsatisfiedLinkError`.
