# ZyX Virtual v0.2.3-alpha.1

Pré-lançamento experimental com duas correções reportadas durante a inicialização do QEMU no Galaxy A07.

## Correções

- O processo define o socket QMP em `cacheDir/zyx-qmp-<pid>.sock` e valida que o caminho fique abaixo de 108 bytes. O teste cobre o caminho realmente construído pelo launcher.
- Cada nova tentativa começa um `qemu.log` limpo. A mensagem antiga com `files/.../run/qmp.sock` pode ter vindo de uma execução anterior, pois versões anteriores acrescentavam logs; no APK desta versão, essa linha não deve ser confundida com uma inicialização atual.
- Empacotado o keymap `en-us` do source QEMU 11.1.2, fixado por SHA-256. O launcher passa o diretório do mapa explicitamente ao QEMU via `-L`, para eliminar `could not find keymap file for language 'en-us'`.

## Validação

Build local `BUILD SUCCESSFUL`; 34 testes Kotlin em standard/clone e 4 testes Python passaram. Os 71 arquivos do runtime no APK foram verificados por tamanho e SHA-256; a keymap está incluída. A CI do GitHub Actions passou no [commit `f95f841`](https://github.com/tzx-dev/ZyXVirtual/actions/runs/39053613140). O uso em aparelho físico ainda não foi confirmado.

## Limitações

Não testado no Galaxy A07 4G. O teste local valida construção de argumentos e integridade/empacotamento da keymap, mas não prova boot completo do guest ou o comportamento da VNC no telefone. O `.zyxos` segue sendo bootstrap upstream sem o overlay ZyX aplicado.
