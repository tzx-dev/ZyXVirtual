# ZyX Virtual v0.3.1

## Correções

- Nova versão de atualização (`versionCode 112`) para que o atualizador do aplicativo reconheça a correção.
- O app rejeita pacotes ZyXOS que contenham userdata pré-aquecido incompatível com metadata-encryption/checkpoint.
- A ROM recomendada é a variante limpa, com o `vdb.qcow2` original esperado pelo guest.
- Mantida a recuperação automática de estados persistentes interrompidos.
- Mantido o modo `userdebug`, `ro.debuggable=1`, ADB TCP e suporte a `adb root`.

## ROM recomendada

Use `ZyXOS-lineage-23.2-20260917-clean-userdata.zyxos`. A variante `prewarmed-data-alpha` não deve ser usada: o log mostrou `Checkpoint: No magic`, ausência da chave de metadata encryption e falha ao criar `/data`.
