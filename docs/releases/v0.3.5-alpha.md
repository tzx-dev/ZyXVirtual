# ZyXVirtual 0.3.5-alpha

Esta release é baseada diretamente na `v0.3.2-alpha`.

- Corrige o boot do Binder: o app agora tenta uma conexão real ao socket do `binderd` antes de iniciar os serviços Android e o `system_server`.
- Ignora sockets antigos deixados por uma instância anterior do daemon.
- Inclui o final do log do `binderd` quando o daemon não aceita conexões, facilitando o diagnóstico.
- Mantém o restante do código, recursos e comportamento da `v0.3.2-alpha`.
