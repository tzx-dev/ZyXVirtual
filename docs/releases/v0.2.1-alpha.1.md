# ZyX Virtual v0.2.1-alpha.1 — pré-lançamento experimental

Esta versão atualiza a interface principal e melhora o diagnóstico quando o processo QEMU encerra. **Ainda não é uma ROM ZyX OS final e não foi validada em aparelho físico.**

## Novidades

- Home nativa Compose reorganizada com base na linguagem visual de `site/index.html` e `site/style.css`: hero em gradiente, cards, recursos, guia de uso e navegação inferior. Os textos e ações foram adaptados ao ZyX Virtual em Português Brasileiro; não foram copiadas as alegações antigas do AEmulator.
- Os controles da tela de VM receberam a cor de marca.
- O banner após a saída do QEMU pode ser tocado para ver até 24 KiB finais de stdout/stderr de `qemu.log`, copiar o conteúdo ou exportar o arquivo pelo seletor SAF. Um destino de nuvem, como Google Drive, depende do provedor disponível no aparelho.
- A atualização preserva o launcher QEMU system-mode ARM64, VNC, instalação `.zyxos` e persistência de discos do alpha anterior.

## Validação

- 28 testes Kotlin executados no total entre as variantes standard e clone; sem falhas, erros ou skips.
- Testes Python do empacotador, verificações de sintaxe e preflight dos 70 assets QEMU passaram.
- Build standard debug, clone debug e standard release unsigned concluído localmente.
- Não havia telefone listado em `adb devices`; esta versão não foi instalada nem executada em Android físico.

## Limitações importantes

- O APK não contém a ROM `.zyxos`; ela deve ser importada separadamente pelo usuário. O bootstrap disponível é upstream `lineage_virtio_arm64only`, não recebeu o overlay ZyX e não é uma ROM ZyX OS final.
- A causa de um encerramento com código 1 ainda não foi identificada. O código é apenas o status do processo; para investigar no telefone, toque no banner, copie/exporte `qemu.log` e compartilhe o conteúdo relevante. O log pode conter caminhos ou informações de diagnóstico do aparelho; revise antes de compartilhar.
- O smoke test de host chegou ao Android `init` e à descompressão de APEX, mas não confirmou zygote/framework. O Galaxy A07 4G não foi testado; desempenho, temperatura e acesso KVM no Helio G99 não foram medidos.
- Os 28 testes e a verificação de assets validam build/contratos locais, não boot end-to-end. O seletor SAF/Drive e a exportação também ainda precisam de validação no aparelho.
- O manifesto `.zyxos` usa hashes para detectar corrupção, mas ainda não tem assinatura criptográfica do publicador.
