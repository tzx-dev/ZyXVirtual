# ZyX Virtual v0.2.2-alpha.1

Pré-lançamento experimental. Esta atualização refina a interface e corrige o caminho do socket QMP observado ao iniciar a VM.

## Alterações

- Home reduzida à biblioteca compacta; removida a landing page longa.
- Cartões, botões e painel de logs/diagnóstico atualizados com azul `#3D5AFE` e bordas arredondadas.
- Interface em Português Brasileiro.
- Socket QMP movido para caminho curto em `cacheDir` para evitar o limite de 108 bytes dos sockets Unix.
- Validação local: 30 testes Kotlin (standard/clone), 2 testes Python e integridade de tamanho/SHA-256 dos 70 assets QEMU empacotados.

## Limitações conhecidas

- Não testado em aparelho físico, inclusive no Samsung Galaxy A07 4G. O build e os testes locais não confirmam boot completo, execução QEMU no Android, VNC/input ou desempenho TCG no telefone.
- O `.zyxos` permanece um bootstrap upstream `lineage_virtio_arm64only`; o overlay `lineage_zyx_virtual` ainda não foi compilado/aplicado.
- O QEMU TCG pode ser lento e o suporte a KVM/AVF não foi verificado.

Consulte [`docs/build/build-report.md`](../build/build-report.md) para artefatos, hashes e comandos de validação.
