# ZyX Virtual 0.1.1-alpha.1 — prévia de teste

Esta é uma prévia alpha destinada a testes; não é uma versão estável.

## Incluído

- Interface do aplicativo em português brasileiro.
- Fluxo exclusivo para selecionar e validar um pacote ZyX OS no formato `.zyxos`, baseado no alvo virtual ARM64 da LineageOS 23.2 / Android 16, sem Google Apps.
- Verificação de identidade do pacote, caminhos seguros e hashes SHA-256.
- Atualizador com mensagens em português.

## Limites importantes

- Esta release candidata contém somente o aplicativo Android; **não inclui a ROM ZyX OS nem um pacote `.zyxos`**.
- O motor QEMU system-mode ainda não está integrado ao APK; o boot do sistema convidado permanece desabilitado.
- É um APK `debug`, assinado com a chave de desenvolvimento padrão, não com uma chave privada de publicação.
- Não foi instalado nem testado em um telefone físico; o Galaxy A07 não foi validado.
- Destina-se a teste técnico, não a uso diário ou distribuição pela Play Store.
