# ZyX Virtual v0.2.6-alpha.1

Corrige o diagnóstico da tela de execução. O Android guest grava kernel, init e framework em `serial.log`; o stdout/stderr do processo QEMU fica separado em `qemu.log`. A versão anterior tentava abrir apenas `qemu.log`, que normalmente fica vazio mesmo quando o guest está produzindo logs.

Agora a tela de erro, a exportação e o diálogo de diagnóstico apontam para o `serial.log` real do guest. Isso permite identificar corretamente falhas de SELinux, APEX, zygote e `system_server` durante o boot.

Esta versão não transforma o bootstrap atual em uma ROM LineageOS final: a compilação completa ainda requer a árvore LineageOS/device tree e um host de build apropriado.
